# DAMA Docs

Source of the public DAMA documentation at [docs.usedama.com](https://docs.usedama.com), built with [Mintlify](https://mintlify.com).

## Local preview

```bash
npx mint dev
```

Then open http://localhost:3000.

## Checks

```bash
npx mint validate
npx mint broken-links
```

Changes pushed to `main` are deployed by Mintlify.
